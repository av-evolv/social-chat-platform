# Lessons

## 2026-09-15 — Optional coordination tools

The user withdrew GitHub Projects setup because access is unavailable and asked to close M0 and start M1.

When optional tooling is unavailable and the user withdraws that scope, adopt the available coordination workflow as the durable approach. Remove pending-setup requirements, preserve completed work and cancellation history, and close the withdrawn scope as not planned. Do not keep an otherwise completed milestone open or repeatedly seek access to a tool the user no longer wants to pursue.
